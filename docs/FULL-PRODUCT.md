# NAVRYNT full application and recording evidence

The public demo and the full application are separate components. The application combines a Python backend, React frontend, provider integrations and configured model services. The public repository distributes the static demo and selected historical captures, not the private application or licensing tools.

## Attribution and format

- ADSB.lol: https://www.adsb.lol/docs/open-data/api/ — ODbL 1.0.
- OpenStreetMap contributors: https://www.openstreetmap.org/copyright
- USGS: https://earthquake.usgs.gov/earthquakes/feed/
- GLEIF: https://www.gleif.org/en/lei-data/access-and-use-lei-data/level-2-data-who-owns-whom
- LibriSpeech: Vassil Panayotov, Guoguo Chen, Daniel Povey, Sanjeev Khudanpur (2015), https://www.openslr.org/12 — CC BY 4.0.

Original MP4/PNG pairs retain their reviewed bytes and visible source attribution. Clips are silent, usually 3–4 fps successive actual captures. The 24-second tour edits four six-second chapters, with titles and reading holds, and no interpolated motion. Caption tracks describe the workflow, not an audio transcript. [Media checksums](../assets/proof/SHA256.json).

## Limits

Research speech comparison is not a population identity-accuracy benchmark. Historical public positions are not a current tracking feed. Company accounting parentage is not natural-person beneficial ownership. No record here establishes that all providers, all biometric modalities, all 32 catalogue operations or production deployment combinations have been independently verified. Missing credentials or model dependencies remain prerequisites. No raw biometric datasets or model weights are included.
